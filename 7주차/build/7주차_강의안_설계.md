# 7주차 강의안 설계

## 수업 범위

- 주제: 영상법과 변수 분리법
- 교재: Griffiths 4판 §3.1 복습, §3.2 영상법, §3.3 변수 분리법
- 일정: 2026년 10월 15일 강의, 10월 19일 연습
- 발표자료 표기: `WEEK 07`, `7주차`

## 학습 목표

1. 유일성 정리로 영상법의 타당성을 설명한다.
2. 접지된 평면과 구에 대한 영상전하의 위치와 크기를 정한다.
3. 라플라스 방정식에 변수 분리법을 적용해 직사각형 영역의 급수해를 만든다.
4. 구 좌표계의 축대칭 해를 르장드르 다항식으로 표현한다.

## 슬라이드 구성

- 1–4: 표지, 수업 목표, 학습 지도, 영상법 도입
- 5–12: 접지된 무한 평면의 영상법과 검산
- 13–21: 접지된 구, 고립된 구, 영상법의 적용 범위
- 22–29: 직교좌표계의 변수 분리법과 푸리에 계수
- 30–34: 구 좌표계의 변수 분리와 르장드르 다항식
- 35–36: 연습문제 연결, 종합 및 중간고사 범위

## 제작 기준

- 16:9, 흰색·검정·네이비·파란색 중심의 기존 강의안 디자인을 유지한다.
- 한글 본문은 Apple SD Gothic Neo, 수식과 수학 레이블은 Times New Roman 계열로 조판한다.
- 중심 수식은 MathJax로 렌더하고, 평면·구·좌표축·경계 도식은 편집 가능한 PPT 개체로 유지한다.
- 학생용 용어는 한글판 Griffiths 기준의 `영상법`, `변수 분리법`, `경계조건`, `유일성 정리`, `쌍극자 모멘트`를 사용한다.
- 모든 장표에 교재 절과 강의 범위를 발표자 노트의 Sources 블록으로 기록한다.

## 검증 항목

- PPTX 36장과 발표용·A4 PDF의 페이지 수가 일치하는지 확인한다.
- 영상전하는 실제 영역 밖에 있고, 도체 표면의 전위가 지정된 경계값과 일치하는지 확인한다.
- 영상전하가 만드는 힘과 에너지에서 계수 1/2의 적용 여부를 구분한다.
- 직교·구 좌표계 급수해의 경계조건과 차원을 확인한다.
